## ⚡ 1-Minute Quickstart

Clone the repository and install the workspace:

```bash
# 1. Clone the repository
git clone https://github.com/devesh1205-psy/agent-sentinel.git

# 2. Enter directory
cd agent-sentinel

# 3. Install optional dev tooling (e.g. file watchers)
npm install
```

*(Optional: Run `npm link` to make the `sentinel` command available globally across your system).*

## 🛠️ Operating System Specific Notes

### macOS (Apple Silicon / Intel)
* Native support across all macOS versions.
* If port 3333 is occupied by another service, pass a custom port:
  ```bash
  PORT=3335 node src/hud/server.js
  ```

### Linux (Ubuntu, Debian, Fedora, Arch)
* Works out of the box with standard Node.js LTS.
* To run the HUD in the background on headless servers:
  ```bash
  nohup node src/hud/server.js > sentinel-hud.log 2>&1 &
  ```

### Windows (PowerShell / Command Prompt / WSL2)
* Works in PowerShell, CMD, or Ubuntu under WSL2:
  ```powershell
  # PowerShell / CMD
  node src\hud\server.js
  node .\bin\sentinel.js watch
  ```
